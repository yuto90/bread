# Source requirements

`idea.md` records the wider Bread product vision. `poc.md` governed the historical
connection-only feasibility experiment. Bread is now entering product development;
the current [support contract](../supported-scope.md) describes implemented behavior
and [foundation record](../production-foundation.md) describes the first milestone.
The full vision is not an implementation claim. In particular, automatic hole
assignment remains core; simulation and an AI service are not part of this work.

These reference texts were reconstructed from the supplied requirement documents
on 2026-10-01. Their contents are preserved as historical input. Later extensions,
including the Playground and mixed-parts family, are documented separately.
