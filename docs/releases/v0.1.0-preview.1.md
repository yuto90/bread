# Bread v0.1.0-preview.1 — early preview

Bread の初回 early-preview です。接続を記述した `.bread` から、自動配置した
ブレッドボード配線図を SVG として生成します。物理接続を独立に再構築し、
論理ネットとの整合性を検証します。安定版・汎用回路設計ツールではありません。

## 対応する8部品型

`arduino-uno-r3`、`resistor`、`led-5mm-red`、`pushbutton-b3f1000-formed`、
`potentiometer-3296w`、`dht22-bare`、`diode-1n4148`、`capacitor-c315c104`。
認識する部品型の一覧であり、任意の組み合わせに対応するものではありません。

## 対応する4回路ファミリー

1. Uno D12/D13、220Ω 抵抗、赤色 LED、GND1 の1分岐
2. D13 から降順の連続ピンを使う3〜6個の抵抗付き LED 分岐（共通 GND1）
3. Uno、LED、3抵抗、加工済みリードのボタン、10kΩ 半固定抵抗、裸の DHT22 を使う指定の複合配線構成
4. Uno D12/D13 → 220Ω 抵抗 → 1N4148 A/K → LED A/K → GND1。5V/GND1 間の無極性 C315C104 100nF は最大1個

公開サンプルは `blink`、`three-leds`、`6-leds`、`temperature-alarm`、
`diode-led`、`diode-decoupling` の6種類です。

## 重要な制限

- 固定の30行・300穴・電源レールなしのブレッドボードを使用
- LED 2分岐は未対応。7〜12分岐は配置容量エラー。任意回路・手動配置には非対応
- 配線は交差することがあります。交差は接続点ではありません
- ボタンと1N4148のリード加工を仮定。部品の機械的な収まり、DHT22下の配線空間、実機組立は未検証
- 電圧・電流・熱・電気安全を評価せず、回路シミュレーションやファームウェア実行も行いません。安全な組立や実機動作は保証しません
- 編集内容は元のタブのメモリー内だけに保持。再読み込み・タブを閉じる・サンプル切り替えで失われます。Docs 別タブ化は自動保存ではありません
- 検証対象ランタイムは Node.js 24.19.0。ブラウザー検証は Chromium のデスクトップ/スマートフォン幅。Safari・Firefox・実機モバイルの動作保証ではありません

正確な接続条件は [対応範囲](../supported-scope.md) を参照してください。

## 検証方法

`npm run verify`（型・コア/CLI/DOMテスト・再現可能なビルド）と
`npm run test:browser`（両表示幅の Chromium 回帰テスト）を使用します。
CI 成功後、通常の PR マージと既存の Cloudflare Pages 自動デプロイを経て公開します。
